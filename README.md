# Планинг — личный планировщик

Простое веб-приложение: задачи, рутины, вид по дням и по часам, делегирование.
Работает как сайт (ссылка) и как приложение на телефоне/компьютере (PWA).
Данные хранятся прямо в браузере устройства (localStorage) — ничего никуда не отправляется.

## Структура файлов

```
index.html   — точка входа, подключает шрифты, React и стили
styles.css   — ВСЕ цвета, шрифты и радиусы скруглений (дизайн-токены)
app.jsx      — логика приложения (JSX, транспилируется в браузере, сборка не нужна)
manifest.json — настройки PWA (имя, цвет, иконки)
sw.js        — service worker для офлайн-работы
icons/       — иконки для установки на телефон
```

Сборщика (webpack/vite) нет специально — JSX компилируется прямо в браузере через Babel
(подключён в index.html). Значит, чтобы внести правки, достаточно отредактировать файл
и обновить страницу — не нужно ничего собирать или устанавливать.

## Как посмотреть локально

Открыть `index.html` двойным кликом браузер может отказаться загрузить (из-за CORS
для fetch app.jsx). Проще всего поднять локальный сервер:

```bash
cd planner-app
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

или через Node: `npx serve .`

## Как выложить в интернет (бесплатно, 5 минут)

Любой из вариантов даст постоянную ссылку, доступную с телефона и компьютера:

**Netlify (проще всего)**
1. Зайти на netlify.com → Add new site → Deploy manually
2. Перетащить папку `planner-app` в окно браузера
3. Готово — ссылка выдаётся сразу

**GitHub Pages**
1. Создать репозиторий, загрузить туда файлы из `planner-app`
2. Settings → Pages → Source: выбрать ветку `main` и папку `/root`
3. Ссылка появится в том же разделе через пару минут

**Vercel**
1. vercel.com → New Project → загрузить папку или подключить GitHub-репозиторий
2. Deploy

## Как установить как приложение на телефон

- **Android (Chrome)**: откройте сайт → в приложении появится кнопка «⬇ Установить»,
  либо через меню браузера ⋮ → «Установить приложение»
- **iPhone (Safari)**: откройте сайт → кнопка «Поделиться» (квадрат со стрелкой) →
  «На экран «Домой»». Safari не поддерживает автопредложение, только этот способ
- **Компьютер (Chrome/Edge)**: значок установки появится в адресной строке справа

После установки иконка появится на рабочем столе/экране, приложение будет открываться
без адресной строки браузера.

## Как встроить свой дизайн

1. **Цвета, шрифты, скругления** — правь переменные в начале `styles.css`
   (`--color-ink`, `--color-paper`, `--font-display` и т.д.). Всё остальное в файле
   и в `app.jsx` ссылается на эти переменные, так что достаточно поменять значения
   в одном месте.
2. **Палитра цветов для дел** — массив `PALETTE` в начале `app.jsx` (или
   `--palette` в styles.css, если решишь читать её оттуда).
3. **Иконки для дел** — объект `ICONS` в `app.jsx`, сейчас это эмодзи;
   можно заменить на SVG-компоненты или картинки.
4. **Вёрстка/компоненты** — всё в `app.jsx`, каждый визуальный блок — отдельная
   функция (`ItemRow`, `FormModal`, `Section` и т.д.), их можно переписывать
   по отдельности, не трогая логику хранения данных.
5. Если позже захочешь пересобрать всё на полноценный React-проект со сборкой
   (Vite и т.п.) — структура компонентов и данных в `app.jsx` перенесётся почти
   без изменений, поменяется только способ подключения (import/export вместо
   глобальных `React`/`ReactDOM`).

## Важно про данные

localStorage привязан к конкретному браузеру на конкретном устройстве. Если открыть
сайт в другом браузере или на другом устройстве — список будет пустым. Если понадобится
синхронизация между устройствами, это отдельная задача (нужен бэкенд или облачное
хранилище) — дай знать, если захочешь её добавить.
